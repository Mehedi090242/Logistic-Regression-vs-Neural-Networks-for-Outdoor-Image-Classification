This project compares the performance of logistic regression and neural
network models for classifying outdoor versus indoor images from the
Columbia Image Library dataset. We assess both models using sensitivity,
specificity, misclassification rate, and AUC metrics, with features
derived from median RGB values extracted through a 10×10 grid image
processing approach. Results demonstrate that the neural network (AUC
= 0.733) outperforms logistic regression (AUC = 0.649) across all evaluation
criteria, suggesting its superior ability to capture complex patterns
in image data.
